
## Project Objectives
- Explore the relationship between various features (such as age, gender, class) and survival rates.
- Create visualizations to present key insights, trends, and patterns.
- Use Python libraries like **Matplotlib**, **Seaborn**, and **Pandas** to generate a variety of plots including bar charts, histograms, pairplot, boxplot, scatterplot and correlation heatmaps.
- Provide clear and interactive visual representations of data to aid in understanding the factors that influenced survival during the Titanic disaster.

## Technologies Used
- **Python**
- **Pandas**
- **Matplotlib**
- **Seaborn**
- **Jupyter Notebook**
